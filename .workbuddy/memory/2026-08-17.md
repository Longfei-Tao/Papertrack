# 2026-08-17

## papertrack-web 账号系统改造（续上午的看板）
- 需求：师姐要能自己改自己的论文，不能都由用户一个人用共享口令改。
- 方案（用户选"管理员帮建账号"）：Cloudflare Pages + D1 加轻量账号系统，无外部服务、免费。
- 改动：
  - schema.sql：新增 users / sessions 表；papers 增加 owner_id + owner_name；内置 admin 种子（admin / papertrack，PBKDF2-SHA256 哈希，由 _genseed.mjs 生成，与 Worker 端 crypto.subtle 算法一致）。
  - functions/_lib/auth.js：共享鉴权（密码哈希、token、Bearer 解析、getUser、publicUser、json）。
  - functions/api：login.js、logout.js、me.js（当前用户/改密）、users.js（管理员列表/创建）、users/[id].js（删除）。papers.js 改为 GET 公开 + POST/PUT/DELETE 需登录并校验归属（本人或 admin）。
  - 前端：登录弹窗、用户菜单、只看我的、用户管理弹窗、改密弹窗；负责人自动填为当前账号显示名。
  - wrangler.toml 移除 EDIT_TOKEN；README 重写为账号制流程。
- 验证：全部 JS 语法检查通过；前端 44 个 getElementById ID 与 HTML 全部匹配；静态服务返回 200。沙箱无网络无法跑 wrangler 端到端。
- 待用户本机部署：wrangler d1 create → schema 建表 → pages deploy；登录 admin/papertrack 后改密、建师姐账号。
